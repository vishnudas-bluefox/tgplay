tgplay for macOS

Watch Telegram video while downloading on your Mac

Telegram usually waits until the whole file is saved. tgplay lets you play that video in VLC while the download is still running.

brew install vishnudas-bluefox/tap/tgplay
brew install --cask vlc
tgplay

How to watch while downloading

  1. Start the video download in Telegram for Mac.
  2. Open Terminal and type tgplay.
  3. Use the arrow keys to highlight the file.
  4. Press Return, pick VLC, press Return again.

Nothing starts until you confirm the file and the player.

Questions

Can I watch a Telegram video on macOS while it downloads?

Yes. That is what tgplay does. It finds the in-progress Telegram file on your Mac and opens it in VLC.

Is this an app from the App Store?

No. It is a small free Terminal tool. You install it with Homebrew, then run tgplay.

Does it upload my Telegram videos?

No. It only reads files already on this Mac and starts VLC, IINA, or mpv.
